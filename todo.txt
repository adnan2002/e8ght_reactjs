if you make an authenticated request to:

GET /users/me/freelancers/{freelancer_id}/services/{service_id}/availability

Query Paramters:
| Name   | Type                | Required | Example      |
| ------ | ------------------- | -------- | ------------ |
| `date` | string (YYYY-MM-DD) | yes      | `2025-12-01` |

only date is the query paramter

Path Parameters:
| Name            | Type    | Required |
| --------------- | ------- | -------- |
| `freelancer_id` | integer | yes      |
| `service_id`    | integer | yes      |

Example:

GET /users/me/freelancers/1/services/1/availability?date=2025-12-01
